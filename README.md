# Ihor Hrudnyy

**I started with a business. Then built tools to run it.**

Founder of [Italeen](https://italeen.com). Building [Artisello](https://play.google.com/store/apps/details?id=com.artisello.app).

### [→ View the portfolio](https://artisello.github.io/showcase/)

I run a real artisan-food commerce business. That meant handling supplier-specific parcels, VAT, unit pricing, and the operational headaches behind one checkout. I started developing focused WooCommerce tools to address those problems.

| Built | Why it matters | Evidence |
| --- | --- | --- |
| **Italeen** | Operating multi-producer e-commerce business; Invitalia funding and Kilometro Rosso workspace | [Live business](https://italeen.com) · [Case study](projects/italeen.md) |
| **Commerce engine** | Custom multi-artisan shipping, proportional shipping VAT, unit-price logic and storefront theme | [Architecture](projects/commerce-stack.md) |
| **Artisello mobile** | Android food-discovery app with map-based exploration and personal experiences | [Google Play](https://play.google.com/store/apps/details?id=com.artisello.app) · [Product notes](projects/artisello.md) |
| **Supplier Portal** | Narrow supplier order-confirmation and exception workflows | [Pilot-stage case study](projects/supplier-portal.md) |
