# showcase

Showcase of my private projects, without making the original repositories public.

## Come funziona

In questa repository pubblico solo materiale "safe":

- descrizione del progetto
- tecnologie usate
- screenshot/GIF/video
- risultati ottenuti

Il codice sorgente delle repository private resta privato.

## Private project showcase template

Usa questa struttura per ogni progetto:

```md
### Nome Progetto
- **Tipo:** Web app / API / Mobile / Tooling
- **Stack:** ...
- **Problema risolto:** ...
- **Cosa ho implementato:** ...
- **Risultati:** ...
- **Demo pubblica (opzionale):** ...
- **Codice sorgente:** Repository privata (accesso su richiesta)
```
