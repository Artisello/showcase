# Reviewer guide

**The shortest route:**

1. [See the live portfolio](https://artisello.github.io/showcase/) — a visual overview of work completed.
2. [Visit Italeen](https://italeen.com) — a real operating artisan-food commerce business.
3. [Read the commerce architecture](projects/commerce-stack.md) — producer-specific packages, proportional VAT, unit prices, theme separation.
4. [Open the Android app listing](https://play.google.com/store/apps/details?id=com.artisello.app) — Artisello is publicly listed.
5. [Review the Supplier Portal](projects/supplier-portal.md) — a codebase/pilot effort, **not** a claimed launched SaaS.

## What is original about this work?

The same person has operated the commerce business and worked on the software needed to solve its problems. Most case studies describe the operational constraint first and the implementation choice second.

## What is not being claimed?

- Private source code is not publicly browseable through this repository.
- Not every feature in an original project's documentation is deployed on the storefront.
- Trade, BART and the independent API are early-stage efforts; no production marketplace or financial product is asserted.
- Customer counts, revenue figures, performance guarantees and unrelated vanity metrics are intentionally excluded.

See [evidence and disclosure](EVIDENCE.md) for the distinction between public proof, project documentation and founder-provided accounts.
