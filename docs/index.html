02 / Engineering approach

Complexity belongs in the right place.

These boundaries matter when software has to process real orders—not only look good in a demo.

One responsibility per component.

I prefer small, explicit ownership boundaries over a large plugin that silently changes prices, shipments and presentation at once.

  1. 01WooCommerce owns prices, tax configuration and order lifecycle.
  2. 02Multi-Artisan Shipping defines producer packages.
  3. 03Selected shipping methods set commercial shipping charges.
  4. 04Proportional Shipping Tax allocates VAT within each package.
  5. 05Product Compliance owns unit prices; the theme owns presentation.
