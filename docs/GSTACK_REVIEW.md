# Gstack-inspired review discipline

[Artisello/gstack](https://github.com/Artisello/gstack) is a **software development workflow**, not a website theme. We borrow its habits, not its runtime:

- **Founder review / office hours:** Is the page answering a real question for YC reviewers? Is every assertion accurate and proportionate?
- **Design review:** Is this visually distinct without competing with the projects? Can readers scan the answer in under a minute?
- **Engineering review:** Keep the site static, accessible, minimal and maintainable. No extra dependencies for decorative effects.
- **QA:** Verify keyboard navigation, responsive widths, contrast, reduced motion and real links in a browser, not only static code scans.
- **Ship / document:** Review the diff, disclose limits and verify GitHub Pages deployment after merging.

## Tone contract

- **Confident in action, humble in attribution.** Use verbs such as founded, built, tested, learned, contributed.
- **No superiority claims** (e.g., "the real world doesn't care", "no fake demos", "better than other founders").
- Don't claim personal credit for team wins or imply that prototypes are commercially launched.
- Show meaningful outcomes and openly label work in progress.
- Prefer one concrete fact to three dramatic adjectives.

**Not installed:** No gstack runtime, Bun, Claude Code integration or new GitHub Actions were introduced for this static portfolio. Running the actual gstack slash-command pipeline and browser QA requires an appropriately configured agent environment.
